# Security

Report a vulnerability privately through GitHub: the repository's **Security** tab, **Report a
vulnerability**. Please do not open a public issue for it.

In scope: the project's tools (they run on contributors' machines and build VMs), its CI
workflows, and anything that could make the repository distribute something it must not
(binaries, recordings, secrets). The reconstructed client itself is a reconstruction of a 2004
program; report its flaws as ordinary issues unless they affect people running it today.
