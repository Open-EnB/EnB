## Local changes

* `wwdebug/wwdebug.h`: Zero Hour's wwdebug.h includes Generals' GameEngine debug.h; gamedebug.h gives the release build's definitions of the macros it uses (all compile to nothing).
* `ww3d2/meshbuild.h`: MeshBuilderClass::MAX_STAGES is 8 in E&B, as in Zero Hour (Renegade and Generals: 2). Found from VertexMaterialClass: E&B's CRCDirty is at +0x6C, 0x30 bytes later than with 2 stages (Mapper[] and UVSource[] are sized by it).
* `wwmath/matrix3d.h`: Zero Hour's Matrix3D helpers (preMul, postMul, mul, mulVector3, mulVector3Array), without Zero Hour's ALLOW_TEMPORARIES rework of the operators (E&B's operator code is Renegade's). Zero Hour's streak.cpp, whose functions match the client, uses them.
* `wwmath/matrix3d.h`: their definitions, verbatim from Zero Hour.
* `wwlib/sharebuf.h`: ShareBufferClass also has Zero Hour's constructor taking a memory-tag argument, ignored in a release build (Zero Hour only stores it in debug builds), so Zero Hour code that passes it compiles beside Renegade code that doesn't. A separate overload, not a default argument: a default would add a push to every existing call. Renegade's class otherwise (no W3DMPO base).
* `wwlib/sharebuf.h`: its definition (the same body as the one-argument constructor).
* `ww3d2/w3d_file.h`: W3dEmitterExtraInfoStruct (Zero Hour's) keeps its 40 bytes, but E&B uses the byte after FutureStartTime as a bool flag (ParticleEmitterDefClass's extra virtual, vtable slot 19 at 0x914520, sets it); named UnknownFlag.
* `ww3d2/part_ldr.h`: ParticleEmitterDefClass has an extra virtual after Set_Future_Start_Time (the client's vtable at 0xB10920, slot 19) that stores a byte argument as a bool: named Set_Unknown_Flag. A uint8 argument into a bool member reproduces the client's test/setne.
* `ww3d2/scene.h`: SceneClass has Zero Hour's scene IDs: Get_Scene_ID() const (returns SCENE_ID_SCENE) right after the destructor, as in the client's vtable (0xB120FC, slot 2). Zero Hour's virtual Render is not in the client.
* `ww3d2/scene.h`: SimpleSceneClass::Get_Scene_ID() (not const, so a new virtual, not an override: as in Zero Hour) returns SCENE_ID_SIMPLE (the client's slot 23 returns 1).
* `wwaudio/audiblesound.h`: AudibleSoundClass has two E&B ints after m_LoopsLeft (+0x7C, +0x80; every later member is 8 bytes later in the client), set to 4 and -1 by both constructors (client 0x9FCA50, 0x9FCE60) and not copied by operator=. Meaning not known: named m_Unknown7C, m_Unknown80.
* `wwaudio/audiblesound.cpp`: both constructors initialise them.
* `wwaudio/sound3d.h`: Sound3DClass has E&B fields: 12 bytes after m_CurrentVelocity (+0x148) and two ints after m_LastUpdate (+0x160, +0x164), all zeroed by the constructors (client 0x9F76A0, 0x9F7C90, 0x9F9220) and not copied by operator=. Meaning not known: m_Unknown148 (a Vector3 by size), m_Unknown160, m_Unknown164.
* `wwaudio/sound3d.h`: the two ints at the end.
* `wwaudio/sound3d.cpp`: both constructors zero m_Unknown148.
* `wwaudio/sound3d.cpp`: and m_Unknown160, m_Unknown164.
* `ww3d2/rendobj.h`: RenderObjClass has Zero Hour's render hook (RenderHookClass, the RenderHook member at the end of the class, Get/Set_Render_Hook, deleted in the destructor) but not Zero Hour's ObjectScale/ObjectColor. Found from the +4 shift of every member after 0x88 in HLodClass, SphereRenderObjClass, RingRenderObjClass, ... (tools/re/layoutdiff.py).
* `ww3d2/rendobj.h`: the destructor deletes the render hook.
* `ww3d2/rendobj.h`: render hook accessors.
* `ww3d2/rendobj.h`: the render hook member.
* `ww3d2/rendobj.h`: RenderObjClass's vtable as in the client (113 slots, at 0xAE84F8; tools/re/vtables.py): one E&B virtual (void, no arguments, empty) before Peek_Animation, named Unknown_Virtual_40.
* `ww3d2/rendobj.h`: Renegade's four user-lighting functions are not virtual (Zero Hour removed them; the client's vtable has no slots for them); kept as plain functions so Renegade's mesh and renderer code still compiles.
* `ww3d2/rendobj.h`: Set_Has_User_Lighting not virtual.
* `ww3d2/rendobj.h`: Save_User_Lighting not virtual.
* `ww3d2/rendobj.h`: Load_User_Lighting not virtual.
* `ww3d2/rendobj.cpp`: both constructors clear the render hook.
* `wwlib/rc4.cpp`: **reconstructed** from the client. E&B's RC4Class: a runtime-built initial key, the 8- and 16-byte key setups inlined into Prepare_Key, inline assembly in the 16-byte setup and RC4(); Print_State and operator= are Zero Hour's. All 5 functions byte-exact (docs/library-matching.md §3.6).
* `wwlib/rc4.h`: **reconstructed** from the client. InitialKey / InitialKeyBuilt statics added; Prepare_Key_8bytes/16bytes removed.
* `wwlib/always.h`: Zero Hour's allocation macros (W3DNEW, W3DMPO_GLUE, W3DMPO) in their release form, appended for the Zero Hour files built against Renegade's always.h.
