No candidate; 267 baseline file pairs and 267 symbol pairs survive each of six trials, with no gains or losses. The canonical runner's immutable original other-TU object provides context; this is not a full-library verification.

The 178-byte client and baseline bodies each contain 58 instructions. Scalar is byte-identical to baseline; named vector adds a 12-byte stack slot and changes stack offsets while leaving the scheduling mismatch. Although explain reports nine aligned rows for the latter, inspect its actual diff: frame class, no improvement.

Scalar accessors compile identically to baseline. The output parameter adds a 12-byte frame, changes x87 component loads to integer copies and leaves 25 rows; it executes the accessor before the virtual callback. Both preserve the translation reads before that callback in the observed output.
3. **Matrix construction:** hypothesized the existing no-initialization bool constructor or its temporary form could affect inline scheduling without changing the matrix's uninitialized initial state. Both compile identically to baseline. This hypothesis was embodied in the prepared source forms before compilation; unlike the first two, the full causal statement was not separately written before compilation.
