## Reconstructed operations and evidence

Retail 0x4BB0E0 receives list, INI object and base string as cdecl arguments,
captures list size, then visits each pair by index. It checks `index < V.size()`
in the inlined list accessor (kv_list.h:73) and `pair` in the writer
(kv_util.cpp:188). Its inlined section helper checks `base`, `append`, and
`section` on lines 45, 46, and 47, respectively; copies base and the key,
changes dots to backslashes, and splits at the last backslash. If there is a
split it appends a separator and prefix to base, returning the suffix as the
entry; otherwise it returns the entire converted key. It evaluates the pair's
virtual value-to-string operation before its virtual type accessor, formats
`{%s}:{%s}`, calls INIClass::Put_String, exits false on the first failure and
otherwise returns true. The local buffers are 0x200 and 0x300 bytes; value
conversion receives a 0x1000-byte shared buffer. Assertions remain active.

The V name is directly supported by the exact client assert text. KVTripleListClass
has a structurally analogous checked Get (kv_tripl.h:90-94). Other added names
are descriptive/neutral guesses, with NAME tags. Candidate helper structure and
the no-argument pair value wrapper are inferences, not recovered source names.
Retail references to 0xBE3B60 occur in both 0x4B6B60 and this writer, while
each immediately calls the same virtual slot +0x0C with size 0x1000: the
candidate represents this as a zero-argument inline KVPairClass wrapper with
a function-local static. The existing list lookup calls that wrapper.

## Storage and remaining proof

Retail references tie the static initializer at 0xBE4E94 to kv_pair.cpp and
kv_util's initializer to 0xBE5098; section storage is at 0xBE4E98 and reader
KeyBuffer is at 0xBE509C. The common-symbol trial does not force their placement
and cannot by itself prove that a final linker gives those addresses. Audit
all target relocations and addends, literal payloads, calls/receivers, full
branches and frame, prior pairs' relocation graphs, final linked storage and
all consumers of changed headers on fresh objects. Reject if those checks fail.
The helper and buffer sizes are evidence-based but their source spelling and
linkage remain inferred. No inline assembly, padding, flags or new dead reads
were introduced. Existing list lookup's preexisting budget expression remains.
