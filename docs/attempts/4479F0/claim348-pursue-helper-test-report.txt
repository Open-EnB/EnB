# Pursue base-helper focused test

Hypothesis: naming and consuming the actual Predict result inside the existing two-argument Pursue helper could change the wrapper's inlining and result lifetime while preserving the helper's own exact out-of-line body. `ph01` changed only that helper from `return Seek(vehicle, Predict(vehicle, target));` to `Vector3 predicted = Predict(vehicle, target); return Seek(vehicle, predicted);`; the original three-argument wrapper remained unchanged. The complete overlay is `pursue-helper-test/ph01`, and the captured source, compiler output, deltas and both analyses are in `runs/ph01`. Source SHA-256 is `9135ab40ea755018a879c298a35b327c7199bc89d328ad77cddc658341bffe1a`.

The compilation succeeded. All four pair sets lost existing pairs at 0x445B30 (base Pursue) and 0x447180 (Follow), with no gains; this violates the mandatory preservation condition. Pursue 0x4479F0 raw and masked SHA-256 are both `470cfb84184bf07f97a13034054d6c81ba368dc939cb5a907744795455b2a6f5`: 249 executable bytes and 22 differing rows versus 247 retail bytes, regressing from baseline 239 / 15. Arrive remains baseline raw/masked `1f5b1df2374436c342d05d6e6e56612c9725e89c42d04dce78f5d493482c3258`, 185 bytes / 9 rows. The target uses source-level original arithmetic, but its emitted x87 and copy scheduling differs from retail. No candidate qualified for a full graph preservation audit, because pair preservation already failed and neither target is exact.

The named initialized helper form is falsified. The proposed combination with pf02's wrapper was conditional on the helper preserving the original 54 pairs; since its independently emitted base body already loses its pair, that combination is ineligible. A subsequent group review identified exact Follow's default-then-assignment pattern as evidence for one contrasting form, tested below. Prior af01/af07 smaller Arrive residues remain ineligible because of their changed floating-point association; the present input did not change Arrive. This result does not establish global exhaustion and remains for the subsequent Sol review.

One input was compiled; there were no failed launches or compiler-invalid forms. Production source was untouched. After the run, staging source compared byte-for-byte equal to the immutable tree; no runner, analyzer, compiler or Wine process remained. Exclusive compiler/staging gate released.

## Contrasting default-and-assignment form: ph02

Hypothesis: default construction followed by assignment of the real Predict result may change its lifetime and inlining differently from ph01, as suggested by exact Follow's default/assignment pattern and the initialization difference between baseline and pf02. In the same original base helper, `Vector3 predicted; predicted = Predict(vehicle, target); return Seek(vehicle, predicted);` was compiled with the original wrappers and all other code unchanged. The overlay is `pursue-helper-test/ph02`; captured input, deltas and both analyses are under `runs/ph02`. Source SHA-256: `5695ed4cd948536837fc0f7e3cd228dd2755ffb07b0a0bb595a2e395bc47307e`.

The compilation succeeded, but all four pair sets lost base Pursue 0x445B30 and Follow 0x447180, with no gains, the same preservation failure as ph01. Pursue 0x4479F0 has raw and masked SHA-256 `4900ca2230a44b55f0770c9e1f1267b61b891063ca9a85b2b84c9459d1afefc5`, 261 executable bytes and 24 differing rows; it is distinct from and worse than ph01 and baseline. Arrive remains the baseline `1f5b1df2374436c342d05d6e6e56612c9725e89c42d04dce78f5d493482c3258`, 185 / 9. No full graph preservation audit applies because the required pairs already failed. Both named prediction forms fail preservation and the target regresses; this focused helper family is closed. A pf02 wrapper combination is ineligible because the old helper itself fails. This does not settle the broader Sol review.

One additional input was compiled, with no failed launch or compiler-invalid form. Production remained untouched, staging compared byte-for-byte equal to the immutable tree, and no compiler, runner, analyzer or Wine process remained. Exclusive compiler/staging gate released.
