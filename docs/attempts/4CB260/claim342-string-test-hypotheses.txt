# Pre-batch hypothesis
VC6 SP4 XSTRING defines data() as an inline call to c_str(), returning the identical NUL-terminated pointer. Substituting data() solely in the existing binary factory argument introduces a real extra inline layer without changing truncation, ordering or lifetime on this toolchain. It may alter VC6's inline budget or schedule of the token buffer and singleton selection, potentially restoring the two retail out-of-line calls or shared child cleanup. Test original and float_second_guard bases together for both float and int. If neither yields a concrete improvement, stop; do not sweep positions. C++98 itself does not guarantee data() termination; any retention would require independent portability consideration.
