  78EA15..78EA22 compute Phrases+(First+Count-1)*0x120; 78EAA9 returns that
  interior address. No result object, ownership transfer, or output argument.
- Player vtable B04A2C+0x0C is thunk 40E64C -> 78ED30. Both stack arguments
  are input pointers, text and end (ret 8). 78EDBC returns its advancing input
  cursor; other exits return zero. It returns neither a count nor bool.
  Thus 78F2FA/314 test a real pointer, while 78F39F/3E0 subtract p only on
  nonzero result. Current source respects the two distinct uses.
- Personality constructor 78F704 installs B04A40. Its slots +0x28/+0x30
  resolve to 78FBB0 (int mood number, -1 fallback) and 78FC20 (borrowed
  BAnimStruct pointer). 78FC5B computes BAnims+(First+Count-1)*8 and 78FC87
  returns it. No temporary class destruction or reference/out parameter.
- 40289C resolves to 78EEF0, the real two-input talk-animation producer.
  Nothing supports replacing it with 78F640, which has different behavior.
- Stream 4C45B0 consumes type/value as bytes (45B4,45F0), length as signed
  word (45E2,4667), and text as pointer (4644); ret 0x10. It copies text
  bytes into its allocated buffer (4673..4682). Existing char/unsigned-char/
  const-char-pointer/short signature agrees. High 24 bits of pushed byte
  values are irrelevant, so MOV AL,[EAX+4]; PUSH EAX at 78F371/378 is not
  evidence for pointer-valued animation or a narrower BAnimStruct field.
